## 🚀 About the Project

The **Dholakpur Banking System** is a Python-based banking application that brings basic banking operations into a web interface.

The project combines Python backend logic, a SQLite database, and frontend technologies to demonstrate how a simple banking application can be organized.

My goal is not just to make the application work, but to understand how each component works and how to build increasingly better projects.

## ✨ Features

- 🧑‍💼 Account creation
- 🔐 PIN-based account authentication
- 💰 Balance checking
- 📥 Deposits and withdrawals
- 🔑 PIN management
- 🗄️ SQLite database integration
- 📜 Transaction record management
- 🌐 Web interface built with HTML, CSS, and JavaScript
- ⚙️ FastAPI backend

## ▶️ Running the Project Locally

**Requirements:** Python 3.13 or a compatible Python version, pip, and Git.

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project folder:

   ```bash
   cd Dholakpur-Banking-System
   ```

3. Install the required packages:

   ```bash
   python -m pip install fastapi uvicorn python-multipart
   ```

4. Start the web application:

   ```bash
   cd web_app
   python -m uvicorn main:app --reload
   ```

5. Open the application in your browser:

   `http://127.0.0.1:8000`

*Run commands from the appropriate project directory. Additional dependencies may be required if the project changes.*
